# Task 1 Comparison Trainer

Тренажер порівняльних структур для IELTS Writing Task 1 (bar chart, line graph,
pie chart, table). Проста статична сторінка — HTML + CSS + JS, без збірки,
без npm, без фреймворків. Весь контент (формули, приклади, речення для
перефразу) лежить окремо в JSON-файлах, тому додавати нове можна без
доторку до коду.

## Структура проєкту

```
task1-trainer/
├── index.html          — розмітка сторінки (шапка, вкладки, контейнер карток)
├── css/
│   └── styles.css      — весь дизайн (кольори, шрифти, картки, кнопки)
├── js/
│   └── app.js          — логіка: завантажує JSON, малює вкладки й картки
├── data/
│   ├── categories.json — список вкладок (ключ, назва, колір, файл)
│   ├── universal.json  — структури категорії "Універсальні"
│   ├── bar.json        — структури категорії "Bar chart"
│   ├── line.json       — структури категорії "Line graph"
│   ├── pie.json        — структури категорії "Pie chart"
│   └── table.json      — структури категорії "Table"
└── README.md
```

## Як додати нове речення для перефразу

Відкрий потрібний файл у `data/` (наприклад `data/bar.json`), знайди
структуру, у яку хочеш додати речення, і додай новий об'єкт у масив
`exercises`:

```json
{
  "practice": "Просте речення англійською, яке студент має перефразувати.",
  "answer": "Готовий правильний варіант із потрібною структурою.",
  "answerNote": "Коротке пояснення українською, що саме змінилось."
}
```

Зберігаєш файл — і на сайті одразу з'являється нове речення. Код чіпати
не треба.

## Як додати нову структуру (формулу)

У той самий файл додай новий об'єкт на верхньому рівні масиву:

```json
{
  "formula": "Нова граматична структура англійською",
  "note": "Коротке пояснення українською, коли її вживати.",
  "example": "Приклад речення з цією структурою.",
  "exercises": [
    { "practice": "...", "answer": "...", "answerNote": "..." },
    { "practice": "...", "answer": "...", "answerNote": "..." },
    { "practice": "...", "answer": "...", "answerNote": "..." }
  ]
}
```

## Як додати нову вкладку (наприклад "Map" або "Process diagram")

1. Створи новий файл, наприклад `data/map.json`, зі структурою такою ж, як
   у файлах вище (масив об'єктів `{formula, note, example, exercises}`).
2. Додай новий рядок у `data/categories.json`:

```json
{ "key": "map", "label": "Map", "color": "#8A6D3B", "file": "map.json" }
```

Вкладка з'явиться сама — `key` має бути унікальним, `color` — будь-який hex,
`file` — назва файлу в папці `data/`.

## Локальний перегляд перед публікацією

Сторінка завантажує JSON через `fetch()`, тому просто відкрити `index.html`
подвійним кліком (`file://...`) не спрацює — браузер заблокує запит.
Запусти локальний сервер у папці проєкту, наприклад:

```
npx serve .
```

і відкрий адресу, яку він покаже (зазвичай `http://localhost:3000`).

## Публікація: GitHub → Vercel

1. Створи новий репозиторій на GitHub і завантаж туди весь вміст цієї
   папки (`index.html`, `css/`, `js/`, `data/`, `README.md`) — або через
   веб-інтерфейс GitHub ("Add file → Upload files"), або через `git`:

   ```
   git init
   git add .
   git commit -m "Task 1 Comparison Trainer"
   git branch -M main
   git remote add origin https://github.com/<твій-акаунт>/<назва-репозиторію>.git
   git push -u origin main
   ```

2. Зайди на vercel.com → "Add New… → Project" → обери щойно створений
   репозиторій.
3. Vercel сам розпізнає це як звичайний статичний сайт (Framework
   Preset: **Other**) — нічого не потрібно змінювати в налаштуваннях
   збірки (Build Command і Output Directory можна лишити порожніми).
4. Тисни **Deploy**. За хвилину отримаєш посилання виду
   `https://<назва-проєкту>.vercel.app`.

Після цього будь-яка зміна в JSON-файлах (нове речення, нова структура,
нова вкладка) — це просто новий коміт у GitHub. Vercel підхоплює його й
переробляє сайт автоматично, без жодних додаткових дій.
